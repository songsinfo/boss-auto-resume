# BOSS 直聘智能筛选投递助手

一个运行在 **Tampermonkey（油猴）** 中的 BOSS 直聘网页辅助脚本，用于按规则筛选职位、检查 HR 活跃状态、辅助发起沟通，并记录已处理的公司与岗位。

支持可选的 DeepSeek / OpenAI 岗位复核。**无需搭建后端服务，也不需要安装 Node.js 或 Python。**

> [!IMPORTANT]
> 本项目是第三方社区工具，与 BOSS 直聘官方无关。脚本可以自动点击“立即沟通”，并在启用相应选项时尝试发送简历图片和常用语。请先确认规则、消息内容和平台使用要求，再自行决定是否启用自动操作。
>
> **公开版本默认不限制目标城市、薪资门槛，也没有预置公司黑名单。** 请不要直接按默认配置批量运行。

## 功能

- **职位初筛**：解析月薪区间和薪数，结合可配置的薪资阈值筛选职位。
- **JD 规则过滤**：排除架构师、猎头/代招、外包、驻场等岗位；支持自定义公司排除名单。
- **HR 活跃度判断**：优先考虑最近 7 天内活跃的招聘方；当页面未显示活跃时间时，当前规则允许通过。
- **工作地点核验**：支持设置目标城市；即便不限制城市，也要求能从页面识别出工作地址。
- **可选 LLM 复核**：支持 DeepSeek / OpenAI；需要用户主动配置 API Key 并授权发送岗位信息。
- **自动发起沟通**：点击“立即沟通”，尝试确认聊天页，并按配置发送简历图片和常用语。
- **去重和台账**：记录已沟通公司、跳过岗位、筛选原因和每日沟通数量；支持导出 JSON。
- **悬浮控制面板**：开始/暂停、设置每日目标、切换 LLM 服务商、绑定简历图片、导出记录。

## 快速开始

### 1. 安装与导入

1. 在浏览器中安装 Tampermonkey 扩展，并确保扩展允许用户脚本运行。
2. 打开仓库中的 [`auto-resume`](./auto-resume)，复制**完整文件内容**。
3. 在 Tampermonkey 中选择“添加新脚本”，粘贴代码并保存。
4. 打开 [BOSS 直聘](https://www.zhipin.com/)，登录自己的账号并进入职位搜索页面。

当前仓库中的源文件名为 `auto-resume`，没有 `.user.js` 后缀，因此推荐**复制到 Tampermonkey 编辑器安装**，而不是把 GitHub 文件链接当成一键安装地址。

### 2. 首次运行前检查

1. **先修改下方源码配置**，确认工作城市、薪资阈值和不希望沟通的公司。
2. 检查 Tampermonkey 脚本中的 `DEFAULT_GREETING_TEXT`。留空时，脚本会尝试点击 BOSS 聊天页的第一条“常用语”，请提前确认该内容。
3. 在悬浮面板中，建议首次运行时**关闭“自动发简历图+常用语”**，先观察岗位筛选与沟通流程是否符合预期。
4. 将“今日目标上限”设为较小值，确认操作正常后再调整。
5. 点击“开始自动投递”；需要停止时点击“暂停自动投递”。

**注意：** 关闭“自动发简历图+常用语”并不会关闭自动点击“立即沟通”。如果不希望脚本发起任何沟通，请不要点击开始按钮。

## 规则与配置

以下配置项位于 `auto-resume` 源码开头，**目前不是控制面板里的可编辑选项**。修改后请同步更新 Tampermonkey 内实际安装的脚本。

~~~javascript
// 自我介绍；留空时尝试使用聊天页第一条常用语
const DEFAULT_GREETING_TEXT = '';

// 留空表示不限制城市
const TARGET_CITY = '';

// 可选：提供给 LLM 的候选人背景；公开仓库不要填写真实个人信息
const LLM_CANDIDATE_PROFILE = '';

// null 表示对应限制不启用
const SALARY_FILTER = {
    maxLowerK: null,             // 薪资下限的允许上界（单位：K/月）
    minUpperK: null,             // 薪资上限须大于此值（单位：K/月）
    minAnnualPackageWan: null   // 年包上限须大于此值（单位：万元）
};

// 只有明确命中“必须/精通/熟练/硬性/必备”及关键词的岗位会降级
const LOWEST_PRIORITY_KEYWORDS = [];

// 已知公司初始去重名单、企业排除名单、外包公司排除名单
const SEED_COMPANIES = [];
const BIG_TECH_BLACKLIST = [];
const OUTSOURCE_BLACKLIST = [];
~~~

### 规则说明

| 项目 | 当前行为 |
| --- | --- |
| 薪资解析 | 解析 `xx-yyK` 及可选的 `·N薪`；日薪、时薪、面议等格式默认跳过 |
| 薪资下限约束 | 设置 `maxLowerK` 后，职位薪资下限超过该值则跳过 |
| 最低薪资期望 | `minUpperK` 和 `minAnnualPackageWan` 至少配置一项后，两项满足**任意一项**即可通过；均为 `null` 时无最低门槛 |
| 目标城市 | `TARGET_CITY` 为空表示不限城市；不为空时要求提取到的工作地址包含该城市 |
| HR 活跃度 | 显示了活跃标签时按最近 7 天判断；没有显示标签时允许通过 |
| 公司去重 | 一个公司被记录为已沟通后，后续岗位按公司名去重 |
| 排除名单 | 两个公司黑名单默认均为空；`SEED_COMPANIES` 用于初始化去重台账 |
| 最低优先级 | 需先填写 `LOWEST_PRIORITY_KEYWORDS`，控制面板的对应勾选才可能影响筛选 |
| 每日目标 | 默认 50，面板可设 1–50；脚本按北京时间（UTC+8）计算日期 |

**台账提醒：** `SEED_COMPANIES` 只会在首次创建台账时作为初始值；以后修改源码中的该数组，不会自动覆盖已保存在 Tampermonkey 里的历史台账。请自行备份后再管理旧数据。

## LLM 复核（可选）

默认只使用本地规则，**没有授权就不会主动向 DeepSeek 或 OpenAI 发送岗位复核请求**。

启用步骤：

1. 在悬浮面板展开“LLM 复核配置”，选择 **DeepSeek** 或 **OpenAI**，确认模型名称。
2. 点击浏览器的 Tampermonkey 扩展图标，选择“**[BOSS助手] 为当前服务商设置 API Key**”。
3. 再选择“**[BOSS助手] 授权当前服务商复核（会发送岗位信息）**”，阅读确认提示。
4. 如不再需要复核，可通过扩展菜单关闭授权或清除 API Key。

| 服务商 | 默认模型 | 请求地址 |
| --- | --- | --- |
| DeepSeek | `deepseek-chat` | `https://api.deepseek.com/chat/completions` |
| OpenAI | `gpt-4o-mini` | `https://api.openai.com/v1/chat/completions` |

开启后，LLM 请求包含**岗位名称、公司名称、薪资、JD 前 1200 个字符**以及系统提示词。**如果你填写了 `LLM_CANDIDATE_PROFILE`，其中的候选人背景也会随系统提示词发送给服务商。** 请不要在这些配置中写入不希望交给第三方处理的信息。

若未授权或未配置 API Key，会回退本地规则；如果已发起 LLM 请求却出现 HTTP 错误、超时或无效响应，该岗位会被保守跳过。

## 简历图片、常用语与台账

- **绑定简历图片**：在面板点击“绑定简历图”并选取本地图片；脚本使用 FileReader 转成 Data URL，保存到 Tampermonkey 本地存储。
- **自动发送**：当“自动发简历图+常用语”开启时，脚本在确认聊天页后尝试上传图片并发送话术。该选项**默认开启**，但未绑定图片时不会凭空生成简历文件。
- **自定义话术**：`DEFAULT_GREETING_TEXT` 非空时尝试发送指定文本；为空时尝试发送 BOSS 聊天页的第一条常用语。
- **导出记录**：面板点击“导出记录”，生成 `boss-ledger-YYYY-MM-DD.json`。其中可能包含真实公司名称、岗位、薪资和沟通时间，请勿将该文件提交到公开仓库。

脚本会在 Tampermonkey 中保存 API Key、简历图片、投递台账、运行状态和配置。这些数据**不是写死在 GitHub 源码里**，但 Tampermonkey 本地存储不应被视为经过端到端加密的保险箱；请保护浏览器环境和扩展权限。

## 隐私与安全

- 公开版源码没有预置个人姓名、手机号、简历内容、个人公司名单或 API Key。
- 代码通过 `GM_xmlhttpRequest` 请求选定的 LLM API；当前元数据中的 `@connect` 只列出 DeepSeek、OpenAI 两个 API 域名。
- LLM 复核请求不会主动携带简历图片、Cookie 或完整聊天记录；**但**启用自动发送后，简历图片和常用语会通过 BOSS 聊天页面发送给招聘方。
- 浏览器插件、本地备份、台账 JSON、截图、Git 历史及提交作者邮箱都可能泄露个人信息。上传任何新文件前应再次检查。
- 建议使用单独的本地配置副本保存个人信息，并避免将该副本提交到公开仓库。

## 已知限制

1. 依赖 BOSS 页面 DOM 结构和文字标签；网站改版可能使选择器失效。
2. **当前“发送成功”的判断并非招聘平台后端回执**：某些路径根据页面状态或输入框是否清空判断，图片上传失败或常用语发送失败后也可能记录已沟通。请人工抽查聊天记录。
3. 无法保证识别所有已沟通岗位、HR 活跃标签、薪资格式或工作地址。
4. 可能遇到网页安全验证、频率限制或平台规则限制；脚本检测到部分相关提示会暂停，**不提供验证码或风控绕过能力**。
5. 每日计数按 UTC+8 日期计算；界面目标上限为 50，并不代表平台允许每日执行 50 次操作。
6. 仅支持 `https://www.zhipin.com/*` 范围内页面，其他域名不在脚本匹配范围。
