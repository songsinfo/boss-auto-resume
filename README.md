# BOSS 直聘智能筛选投递助手

一个运行在 Tampermonkey（油猴）里的第三方网页辅助脚本。可按本地规则筛选职位、轮询自填搜索词、记录已处理岗位与公司，也支持手动授权的 DeepSeek / OpenAI 岗位复核。无需搭建后端。

> [!IMPORTANT]
> 开始后，脚本会尝试点击符合条件岗位的「立即沟通」。不希望联系招聘方时，不要启动。先核对搜索列表和本地规则，并遵守平台使用要求。出现安全验证、操作频繁或按钮不可用时，脚本暂停或跳过，不会强制启用禁用控件。

## 安装和使用

1. 在浏览器安装 Tampermonkey，并允许用户脚本运行。
2. 将 [`auto-resume.user.js`](./auto-resume.user.js) 的完整源码导入扩展并保存。更新时可覆盖旧脚本；避免同时启用两个版本。
3. 打开 [BOSS 直聘](https://www.zhipin.com/) 的职位搜索页。先在页面上设置自己需要的筛选项，或在本地安装副本中配置规则。
4. 确认悬浮面板的当日沟通上限（新版本默认 **1**），再点「开始自动投递」并确认。可随时暂停；首次运行建议保持简历图／话术和 LLM 复核关闭。
5. 如需轮询，先在面板填写搜索词（逗号分隔），再打开「按自填关键词轮询」。它依次替换搜索网址中的搜索词，保留已有职位搜索页网址里的其他筛选参数。仅存在于页面状态、未反映在网址上的筛选项可能无法随轮询保留，请先检查。每个词的沟通和扫描阈值可在面板中设置。

公开源码**不预置城市、行政区、薪资门槛、岗位方向、搜索词、公司名单、个人资料或常用语**。旧版的自动运行、轮询和第三方授权不会自动启用；已在扩展中保存的搜索词、简历图片、API Key 与历史台账可能保留在本机。

## 本地筛选配置

在 Tampermonkey 编辑器中修改脚本开头的常量。请只修改本地副本，勿把个人设置提交到 GitHub。

| 配置项 | 作用与默认值 |
| --- | --- |
| `TARGET_CITY` | 空字符串不检查城市；配置后，地址缺失或不匹配会跳过。 |
| `SALARY_FILTER` | 三项默认 `null`。可设置薪资下限的上界（K/月）、最低薪资上限（K/月）或最低年包上限（万元）。配置两种最低门槛时，满足任意一项即可。仅当启用门槛时，无法解析的薪资才会因薪资规则被跳过。 |
| `INCLUDE_TITLE_KEYWORDS` / `EXCLUDE_TITLE_KEYWORDS` / `EXCLUDE_JD_KEYWORDS` | 均为空；可按标题包含、标题排除或 JD 排除进行字面匹配。 |
| `MAX_HR_INACTIVE_DAYS` | 默认 `null`；设置后检查可识别的活跃标签。未显示标签时允许通过。 |
| `LOWEST_PRIORITY_KEYWORDS` | 默认空；匹配 JD 后是否通过取决于面板的「允许低优先级」。 |
| `SEED_COMPANIES` / `BIG_TECH_BLACKLIST` / `OUTSOURCE_BLACKLIST` | 均为空。前者仅用于首次建立台账，后两项用于公司排除，不会清空已有台账。 |

## LLM 复核（可选）

默认关闭。在面板选择服务商，使用 Tampermonkey 菜单为当前服务商设置 API Key，再单独授权。也可以在菜单中关闭授权或清除 Key。

| 服务商 | 默认模型 |
| --- | --- |
| DeepSeek | `deepseek-chat` |
| OpenAI | `gpt-4o-mini` |

复核仅检查岗位信息中明确的矛盾或无关内容，不使用预置的个人偏好。请求会向选定服务商发送岗位名、公司名、薪资及 JD 前 1200 字符，不会主动附上简历、聊天记录或 Cookie。未配置密钥或未授权时仅走本地规则；请求失败或回复不合格式时保守跳过。不要授权发送不适合交给第三方的岗位数据。

## 简历图、话术与台账

- **简历图和话术默认关闭。** 绑定图片后会保存在 Tampermonkey 本地。启用会话材料选项后，只有检测到对应公司会话并经你确认，脚本才尝试加载图片或发送本地配置的话术。若页面出现图片预览，请人工核对收件人并确认。留空 `DEFAULT_GREETING_TEXT` 不会发送话术，也不会选取聊天页第一条常用语。
- 台账记录沟通和跳过的岗位，支持按公司去重和导出 JSON。其成功状态来自网页提示或会话识别，不是简历或消息送达回执。请在聊天页人工核对。
- API Key、历史台账、搜索词和图片存放在扩展的本地存储中，不能当作加密保险箱。请勿公开个人配置、简历、台账导出、含个人信息的日志或截图。

## 限制与反馈

网站改版可能使选择器、会话确认或滚动位置恢复失效；遇到不确定的沟通结果请人工核对，避免重复操作。面板中的计数上限并非平台授权额度。脚本仅匹配 `www.zhipin.com`。

如需反馈，欢迎提交 [Issue](https://github.com/songsinfo/boss-auto-resume/issues)。请先清除姓名、联系方式、会话内容、API Key 和其他敏感数据。
